Student Marks Calculation System

About the Project
The Student Marks Calculation System is a simple Core Java project that calculates the total marks and percentage of a student. It accepts student details, subject names, and marks from the user at runtime.
The user can choose the number of subjects and enter marks for each subject.

Features
- Accept student ID and name from the user.
- Allow the user to enter any number of subjects.
- Accept subject names and marks dynamically.
- Calculate total marks.
- Calculate percentage.
- Display the student's details and marksheet.
- Use Java classes and objects to organize the program.

Technologies Used
- Java
- Scanner Class
- Arrays
- ArrayList
- Object-Oriented Programming (OOP)

How to Run the Project
Step 1: Install the Java JDK on your computer.
Step 2: Open the project folder in VS Code.
Step 3: Open the terminal and compile the Java files.
javac Main.java Student.java StudentManager.java
Step 4: Run the program.
java Main
